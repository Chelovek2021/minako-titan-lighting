# MinakoTitan Lighting System 🚲💡

Полнофункциональная система управления светом для электровелосипеда MinakoTitan 2.0 с поддержкой WiFi управления.

## 📋 Характеристики

- **Управление фарами**: центральная + две боковые линзованные фары
- **Поворотники**: левый и правый с режимом мигания
- **Задние огни**: стоп-сигнал и габариты
- **Боковые ленты**: адресная лента с различными эффектами
- **WiFi интерфейс**: веб-приложение для управления со смартфона
- **Режимы эффектов**: статический, мигание, пульс, погоня, реактивность на музыку, радуга, стробоскоп
- **Режим сопровождения (Escort Mode)**: фары светят несколько минут после выключения зажигания

## 🛠️ Аппаратные требования

- ESP32 DevKit V1
- Светодиоды/ленты для фар и огней
- Резисторы для ограничения тока
- Конденсаторы для стабилизации питания
- Адресная светодиодная лента (опционально)

## 🚀 Установка и запуск

### 1. Подготовка окружения

```bash
# Установи PlatformIO
pip install platformio

# Клонируй репозиторий
git clone https://github.com/Chelovek2021/minako-titan-lighting.git
cd minako-titan-lighting
```

### 2. Конфигурация пинов

Отредактируй `src/main.cpp` и поменяй временные значения пинов на свои:

```cpp
#define PIN_FRONT_LEFT_TURN 12    // Поменяй на свой пин
#define PIN_FRONT_RIGHT_TURN 13   // Поменяй на свой пин
// ... и так далее
```

### 3. Сборка и загрузка

```bash
# Собери проект
platformio run

# Загрузи на ESP32
platformio run --target upload

# Смотри логи
platformio device monitor
```

### 4. Подключение

1. Найди WiFi сеть `MinakoTitan_Light`
2. Подключись с паролем `12345678`
3. Открой браузер и перейди на `http://192.168.4.1`
4. Управляй светом через веб-интерфейс 🌈

## 🎮 Веб-интерфейс

### Вкладки управления:

- **Side Strip Effects** - управление боковыми лентами
  - Режимы: OFF, Static, Blink, Pulse, Chase, Music Reactive, Rainbow, Strobe
  - Яркость: 0-255
  - Скорость: 100-3000ms
  - Предустановки цветов

- **Front Lights** - фары включить/выключить

- **Turn Signals** - левый/правый поворотник

- **Rear Lights** - стоп-сигнал и габариты

- **Escort Mode** - режим сопровождения (светит после отключения)

- **Master Controls** - включить/выключить все

## 🔌 API Endpoints

```
GET  /api/status                      - Получить текущее состояние
POST /api/brightness?value=255        - Установить яркость
POST /api/mode?mode=1                 - Выбрать режим (0-7)
POST /api/speed?speed=1000            - Установить скорость эффекта
POST /api/color?color=FF0000          - Установить цвет (HEX)
POST /api/turn?direction=left&active=true   - Поворотники
POST /api/brake?active=true           - Стоп-сигнал
POST /api/parking?active=true         - Габариты
POST /api/escort?enabled=true&duration=120 - Режим сопровождения
POST /api/all-on?brightness=255       - Все включить
POST /api/all-off                     - Все выключить
```

## 🎨 Режимы эффектов

- **0 - OFF**: Выключено
- **1 - STATIC**: Постоянное свечение
- **2 - BLINK**: Мигание (вкл/выкл)
- **3 - PULSE**: Пульсирующий эффект
- **4 - CHASE**: Бегущий свет
- **5 - MUSIC_REACTIVE**: Реактивность на музыку
- **6 - RAINBOW**: Радужный цикл
- **7 - STROBE**: Стробоскоп

## 🔧 Примеры использования

### Включить радугу на боковых лентах

```
GET http://192.168.4.1/api/mode?mode=6
```

### Установить яркость 128

```
GET http://192.168.4.1/api/brightness?value=128
```

### Включить левый поворотник

```
POST http://192.168.4.1/api/turn?direction=left&active=true
```
