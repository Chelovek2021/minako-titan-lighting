# MinakoTitan Lighting System 🚲💡

Полнофункциональная система управления светом для электровелосипеда MinakoTitan 2.0 с поддержкой WiFi управления И обработкой входных сигналов с кнопок/пульта.

## 📋 Характеристики

### Выходы (управление светом):
- **Фары**: центральная + две боковые линзованные фары
- **Поворотники**: левый и правый с режимом мигания (500ms)
- **Задние огни**: стоп-сигнал и габариты
- **Боковые ленты**: адресная лента с различными эффектами
- **Режимы эффектов**: статический, мигание, пульс, погоня, музыкальный, радуга, стробоскоп
- **Режим сопровождения (Escort Mode)**: фары светят несколько минут после выключения зажигания

### Входы (обработка кнопок):
- **Левый поворотник** - кнопка/сигнал от пульта
- **Правый поворотник** - кнопка/сигнал от пульта
- **Тормоз** - сигнал от тормозной системы
- **Габариты** - кнопка включения парковочных огней
- **Режим эффекта** - кнопка для переключения режимов боковых лент
- **Яркость +/-** - кнопки для управления яркостью

```

- PIN 33: Сигнал правого поворотника
- PIN 34: Сигнал тормоза

- PIN 37: Кнопка яркость -
```

## 🔗 Схема подключения кнопок

### Вариант 1: Прямые кнопки на ESP32
```
Кнопка ──┬──> PIN (INPUT_PULLUP)
          │
         GND
```

### Вариант 2: Врезка в существующую цепь поворотников
```
Пульт ──┬──> PIN (INPUT_PULLUP) ──┬──> Свет
        │                         │
        └─────────────────────────┘
         (ESP32 - посредник)
```

Когда подается сигнал на вход:
1. ESP32 **принимает** сигнал на INPUT пин
2. ESP32 **обрабатывает** его (debounce, логика)
3. ESP32 **передает** сигнал дальше на OUTPUT пин
4. Свет **включается** с учетом логики эффектов

## 🚀 Установка и запуск

### 1. Подготовка окружения

```bash
# Установи PlatformIO
pip install platformio

# Клонируй репозиторий
git clone https://github.com/Chelovek2021/minako-titan-lighting.git
cd minako-titan-lighting
```

### 2. Конфигурация пинов

Отредактируй `src/main.cpp` и поменяй временные значения пинов на свои:

```cpp
// ВЫХОДНЫЕ ПИНЫ (для света)
#define PIN_FRONT_LEFT_TURN 12    // Поменяй на свой пин
#define PIN_FRONT_RIGHT_TURN 13   // Поменяй на свой пин
// ... и так далее

// ВХОДНЫЕ ПИНЫ (для кнопок)
#define PIN_INPUT_LEFT_TURN 32    // Поменяй на свой пин
#define PIN_INPUT_RIGHT_TURN 33   // Поменяй на свой пин
// ... и так далее
```

### 3. Сборка и загрузка

```bash
# Собери проект
platformio run

# Загрузи на ESP32
platformio run --target upload

# Смотри логи
platformio device monitor
```

### 4. Подключение

1. Найди WiFi сеть `MinakoTitan_Light`
2. Подключись с паролем `12345678`
3. Открой браузер и перейди на `http://192.168.4.1`
4. Управляй светом через веб-интерфейс 🌈

## 🎮 Управление

### Способ 1: Кнопки/Пульт (аппаратно)
```
Левый поворотник (PIN 32)  ──> Левый поворотник мигает
Правый поворотник (PIN 33) ──> Правый поворотник мигает
Тормоз (PIN 34)            ──> Задний стоп-сигнал горит
Габариты (PIN 35)          ──> Задние огни горят
Режим (PIN 36)             ──> Циклирует режимы: OFF → Static → Blink → Pulse → Chase → Music → Rainbow → Strobe → OFF
Яркость + (PIN 39)         ──> +15 к яркости
Яркость - (PIN 37)         ──> -15 к яркости
```

### Способ 2: Веб-интерфейс (WiFi)
- Управление режимами эффектов
- Регулировка яркости
- Регулировка скорости
- Выбор цветов
- Режим сопровождения

## 📋 Логика работы

### Обработка сигналов с дебаунсом:
```cpp
Время дебаунса: 50ms (защита от дрожания контактов)

1. Сигнал поступает на INPUT пин
2. InputHandler проверяет состояние
3. Если стабильно 50ms ──> срабатывает callback
4. LightingManager включает нужный свет
5. PWM управляет яркостью
```

### Приоритеты управления:
```
1. Тормоз (BRAKE) - всегда приоритет (полная яркость)
2. Поворотники (TURN) - мигают 500ms
3. Парковочные огни (PARKING) - фоновое свечение
4. Эффекты боковых лент - из веб-интерфейса или кнопок
```

## 🔌 API Endpoints

```
GET  /api/status                      - Получить текущее состояние
POST /api/brightness?value=255        - Установить яркость
POST /api/mode?mode=1                 - Выбрать режим (0-7)
POST /api/speed?speed=1000            - Установить скорость эффекта
POST /api/color?color=FF0000          - Установить цвет (HEX)
POST /api/turn?direction=left&active=true   - Поворотники
POST /api/brake?active=true           - Стоп-сигнал
POST /api/parking?active=true         - Габариты
POST /api/escort?enabled=true&duration=120 - Режим сопровождения
POST /api/all-on?brightness=255       - Все включить
POST /api/all-off                     - Все выключить
```

## 🎨 Режимы эффектов

- **0 - OFF**: Выключено
- **1 - STATIC**: Постоянное свечение
- **2 - BLINK**: Мигание (вкл/выкл) - регулируется скоростью
- **3 - PULSE**: Пульсирующий эффект - дыхание света
- **4 - CHASE**: Бегущий свет - волна освещения
- **5 - MUSIC_REACTIVE**: Реактивность на музыку (от микрофона)
- **6 - RAINBOW**: Радужный цикл - цветовая волна
- **7 - STROBE**: Стробоскоп - быстрые вспышки

## 🐛 Проблемы?

Если что-то не работает:

1. **Кнопки не реагируют:**
   - Проверь распиновку входных пинов в `src/main.cpp`
   - Убедись, что кнопки подключены к GND и INPUT пину
   - Используй INPUT_PULLUP режим
   - Посмотри в Serial Monitor логи кнопок

2. **Свет не включается:**
   - Проверь распиновку выходных пинов
   - Убедись что питание достаточное (5V для светодиодов)
   - Проверь что PWM каналы настроены верно

3. **WiFi не работает:**
   - Перезагрузи ESP32
   - Проверь SSID и пароль
   - Убедись что в помещении есть сигнал

4. **Дебаунс слишком чувствительный/нечувствительный:**
   - Измени `DEBOUNCE_DELAY` в `include/input_handler.h`
   - Текущее значение: 50ms
   - Увеличь для более стабильного срабатывания (100ms-200ms)
   - Уменьши для большей отзывчивости (20ms-30ms)

## 💡 Примеры использования

### Подключение кнопки поворотника:
```
Сигнал поворотника от пульта ──┬──> PIN 32 (INPUT_PULLUP)
                                 │
                                ESP32
                                 │
                                PIN 12 ──> Левый поворотник (LED)
```

Когда нажимаешь левый поворотник на пульте:
1. Сигнал поступает на PIN 32
2. InputHandler обнаруживает нажатие
3. LightingManager включает PIN 12 в режиме "мигание"
4. Поворотник начинает мигать

### Динамическая смена яркости:
```
Кнопка Яркость+ ──> PIN 39 ──> +15 к текущей яркости (максимум 255)
Кнопка Яркость- ──> PIN 37 ──> -15 от текущей яркости (минимум 0)
```
